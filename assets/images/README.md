# 馬イラストについて

このフォルダに以下のファイル名で画像を配置すると、レース画面の馬が
自動的にその画像に差し替わります。画像が無い場合はCSS/SVGで描いた
オリジナルのデフォルメ馬がそのまま表示されます（エラーにはなりません）。

商用利用可能、またはCC0（パブリックドメイン）の素材のみを使用してください。
既存のゲームやキャラクターのイラストをそのまま使うことはできません。

| ファイル名        | 用途          |
|--------------------|---------------|
| horse1.png          | 1番の馬       |
| horse2.png          | 2番の馬       |
| horse3.png          | 3番の馬       |
| horse4.png          | 4番の馬       |
| horse5.png          | 5番の馬       |
| horse6.png          | 6番の馬       |
| horse7.png          | 7番の馬       |
| horse8.png          | 8番の馬       |

推奨: 横長（2:1程度）の透過PNG。馬番バッジは画像の上に別途重ねて
表示されるため、画像自体に馬番を描き込む必要はありません。
