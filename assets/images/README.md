# 馬画像について

このゲームの馬は **すべてこのフォルダの実画像だけ** で表示されます。
CSS/SVGでの馬の自動生成は行いません。画像が無い場合は、レース画面・
出走馬紹介・投票画面・結果画面のいずれでも「画像がありません」という
プレースホルダーが表示されます（エラーにはならず、ゲーム進行は止まり
ません）。

商用利用可能、またはCC0（パブリックドメイン）の素材のみを使用してください。
既存のゲームやキャラクターのイラスト・デザインをそのまま使うことは
できません。運営（このリポジトリの管理者）が権利関係を確認した画像を
このフォルダに配置する運用です。

ファイル名は馬番（1〜8）に対応しています。馬番とゼッケン色の対応は
毎レース固定です。

| ファイル名        | 馬番 | ゼッケン色 |
|--------------------|------|------------|
| horse_1.png         | 1番  | 赤         |
| horse_2.png         | 2番  | 青         |
| horse_3.png         | 3番  | 黄         |

## 推奨仕様

- 背景透過PNG
- 横向き（サイドビュー）で走っているポーズ
- 高さ40〜60px程度で表示されるため、ぼやけないよう元画像はそれより
  十分大きい解像度で用意する（縦横比はそのまま保たれ、表示側で歪みは
  加えません）
- 馬番バッジは画像の上に別途重ねて表示されるため、画像自体に馬番を
  描き込む必要はありません

## 読み込みについて

- 画像はアプリ起動時に一度だけ読み込み、結果（読み込めた／見つからない）
  をキャッシュします。レース中に毎回読み込み直すことはありません。
- 8頭ぶん（horse_1.png 〜 horse_8.png）を配置すると、次回の描画から
  自動的にそちらが使われます。
