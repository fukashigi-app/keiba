# 馬イラストについて

このフォルダに以下のファイル名で画像を配置すると、出走馬紹介・投票・
レース画面の馬が自動的にその画像に差し替わります。画像が無い場合は
CSS/SVGで描いたオリジナルのデフォルメ馬がそのまま表示されます
（エラーにはなりません）。

商用利用可能、またはCC0（パブリックドメイン）の素材のみを使用してください。
既存のゲームやキャラクターのイラスト・デザインを模倣・コピーすることは
できません。

ファイル名は馬番ではなく「ゼッケン色」に対応しています（馬番と色の
対応は毎レース固定）。

| ファイル名             | 馬番 | ゼッケン色 |
|-------------------------|------|------------|
| horse_red.png           | 1番  | 赤         |
| horse_blue.png          | 2番  | 青         |
| horse_yellow.png        | 3番  | 黄         |
| horse_green.png         | 4番  | 緑         |
| horse_purple.png        | 5番  | 紫         |
| horse_orange.png        | 6番  | オレンジ   |
| horse_white.png         | 7番  | 白         |
| horse_black.png         | 8番  | 黒         |

推奨: 横長（2:1程度）の透過PNG。馬番バッジは画像の上に別途重ねて
表示されるため、画像自体に馬番を描き込む必要はありません。
