# 音源ファイルについて

このフォルダに以下のファイル名で音源を配置すると、自動的に再生されます。
ファイルが無い場合でもエラーにはならず、無音のままゲームは正常に動作します
（コンソールに警告が出るだけです）。

商用利用可能、またはCC0（パブリックドメイン）の素材のみを使用してください。
著作権のある既存ゲームの音楽・効果音は使用しないでください。
Claude Codeが著作権フリー音源そのものを保証して用意することはできないため、
音源ファイルは後から運営側でこのフォルダに追加する想定です。

## BGM（すべてループ再生）

| ファイル名        | 用途                                   |
|--------------------|----------------------------------------|
| bgm-title.mp3       | タイトル画面（落ち着いた期待感のある曲）|
| bgm-entry.mp3       | 出走馬紹介（ゆったり壮大な曲）          |
| bgm-vote.mp3        | 投票受付中（落ち着いた待機BGM）         |
| bgm-race.mp3        | レース中（スピード感のある盛り上がる曲）|
| bgm-result.mp3      | 結果発表（順位発表BGM）                 |

場面が切り替わるたびに、現在のBGMをフェードアウトしながら次のBGMを
フェードインする（クロスフェード）ようになっています
（js/audioManager.js の fadeToBgm）。

## 効果音（SE）

| ファイル名        | 用途                                     |
|--------------------|------------------------------------------|
| click.mp3           | 一般的なボタン操作音                     |
| decide.mp3          | 決定音（新しいレース／START など）       |
| countdown.mp3       | 投票終了直後の短いジングル               |
| tick.mp3            | カウントダウン「3・2・1」の音            |
| gate.mp3            | ゲートオープン                           |
| start.mp3           | スタート（GO!!）                        |
| running.mp3         | 馬の足音                                 |
| cheer.mp3           | 歓声（終盤・最後の直線・ゴール時）       |
| goal.mp3            | ゴール                                   |
| fanfare.mp3         | 結果発表の勝利ファンファーレ             |
| rankup.mp3          | レース中に暫定1位が入れ替わった時の効果音|

対応形式: mp3 / ogg / wav など、ブラウザが再生できる形式であれば拡張子を
変更しても構いません（js/audioManager.js 内のファイルパスを合わせて変更してください）。

## 音量設定

管理画面（⚙ボタン）から、BGM音量・効果音音量・実況音量をそれぞれ
個別に調整できます。
